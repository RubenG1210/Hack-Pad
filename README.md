<h1>My Hackpad</h1>

<h3>Introducing the MINI KEYBOARDDD!!!! This project includes my first PCB Design, 3D Model case for it, and a OLED Screen for Visuals!!</h3>

<h1>Features</h1>
- 3 Programmable keys
- Custom 3D printed case
- XIAO RP2040
- Custom PCB

<h1>Why I Made It</h1>
I wanted to improve my skills, which include PCD and CAD Designing. The main use intended for this a simple, yet effective an useable Copy and Paste mini keyboard
